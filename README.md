# EMBER

Clickable **UI prototype** of a phone-first workout app (black / orange). No real accounts, no native steps, no backend.

**Engineer taking this to production:** start at **[HANDOFF.md](./HANDOFF.md)** (architecture, product rules, what to replace).

## Run

```bash
npm install
npm run dev
```

Open the local URL at ~390px width, or the LAN address Vite prints on a phone.

## Preview

Static host after `npm run build`. SPA fallback is configured for Netlify and Vercel.
