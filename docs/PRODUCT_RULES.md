# Locked product rules

Copy these into tickets. The UI already implements them.

1. **Streak day** = a finished session (at least one logged set, then finish). Rest and abandoned empty sessions do not count.
2. **Home after a completed session has no training CTA.** Extra work is Train-tab only. Extra finishes **add** minutes, kcal, and `sessions` on that calendar day. They do not grow the streak.
3. **Rest is explicit.** Empty day ≠ rest. Empty partner today = “hasn’t trained yet” + **Send reminder**. Logged rest = “rest day”, no remind.
4. **Twin flame** = you and the linked partner both finished a session today. Icon is a **heart**. Copy is **Twin flame**. Partner calendar marks are small hearts. You = filled square.
5. Home countdown is **until tonight’s midnight**, not the 35-hour streak-expiry window.
6. Coach is **SVG pose loops**, not GIFs.
7. Phone-first: shell **430px**, black `#050505`, orange `#FF5A1F`, Space Grotesk.
